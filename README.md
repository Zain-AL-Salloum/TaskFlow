# TaskFlow - Task Management App

TaskFlow is a simple task management application built with Python and FastAPI.
It allows users to create, manage, update, and track their daily tasks.

## Features

- Add new tasks.
- View all tasks.
- Edit existing tasks.
- Delete tasks.
- Mark tasks as completed.
- Track total and completed tasks.
- Store tasks using SQLite database.
- Responsive and clean user interface.

## Technologies Used

- Python
- FastAPI
- SQLite
- HTML
- CSS
- JavaScript
